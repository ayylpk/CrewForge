# Skill: inspect-project

> 指导材料。不能改变权限、Graph 结构、Contract、验收标准、Ledger 或预算；**不能写盘**。

## 何时加载

收到 `architect_task`、认清任务之后的第一件事。

## 做什么

1. 用 `inspectTree` 看当前项目目录（不是想象中的目录，是**真实**文件树）；
2. 判断这是「空项目」还是「已有一部分的项目」：
   - 空 → 下一步走 `bootstrap-project`；
   - 已有 → 逐个 `readFile` 关键文件，弄清上次做到哪、有没有半成品；
3. 用 `search` 找入口文件与关键符号，别靠猜路径；
4. 用 `gitDiff` 看有没有未提交的脏改动（有脏改动要先弄清楚是谁改的）。

## 输出

一份事实清单：已存在哪些文件、哪些是完整的、哪些是残缺的、下一步最小动作是什么。

## 禁止

- 禁止不看文件树就直接 `writeFile`；
- 禁止用"一般项目都会这样"来替代 `readFile` 的真实结果；
- 禁止在这个阶段写任何文件。
