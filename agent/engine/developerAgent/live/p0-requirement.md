# 项目需求：待办清单 Web 应用（todo-lite）

## 背景

我个人需要一个本地跑的待办管理小工具，帮你把每天要做的事记下来、做完的勾掉。

## 目标

做一个单用户的待办清单 Web 应用：浏览器里增删查待办、标记完成，数据落库不丢。

## 功能需求

1. **新增待办**：填写标题（必填）、备注（可选），保存后出现在列表里；
2. **查看列表**：按创建时间倒序展示全部待办，每条显示标题、备注、状态（未完成/已完成）、创建时间；
3. **标记完成 / 撤销**：每条待办可切换"未完成 ↔ 已完成"，已完成的视觉上有区分（如划线或置灰）；
4. **删除待办**：可删除任意一条；
5. **按状态筛选**：全部 / 未完成 / 已完成 三档切换。

## 边界（本期不做）

- 不做注册登录（单用户本地使用）；
- 不做提醒、日历、多端同步；
- 不做富文本，标题和备注都是纯文本。

## 技术与验收期望

- 数据要持久化（重启后记录还在）；数据库选型由你定，轻量优先；
- 接口走 REST + JSON，统一 /api 前缀；
- 前后端分离：backend + frontend 两个目录；
- 交付标准：前后端都能构建通过，核心接口真实可调（返回体结构清晰）。
